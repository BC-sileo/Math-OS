# 数学II：いろいろな式

<small>状態: 概念設計 v0.1。各ページ本文はこれから制作する。</small>

## この単元で獲得する力

- 多項式を展開・因数分解・除法によって目的に合う形へ変形する。
- 分数式を、分母が0にならない条件を保ちながら扱う。
- 実数から複素数へ数の範囲を拡張する意味を理解し、複素数を計算する。
- 二次方程式の解の種類や解と係数の関係を理解する。
- 多項式の値・余り・因数の関係を使い、簡単な高次方程式を解く。
- 等式・不等式が成り立つ理由を、性質に基づいて説明する。

## ページ制作時の共通方針

各ページは、必要に応じて次の順で構成する。

1. 問い・導入：この概念が必要になる状況
2. 直観：具体例や図式で対象をつかむ
3. 定義：曖昧さのない数学的定義
4. 構造：なぜその性質・公式が成り立つか
5. 操作：基本計算・変形の意味と条件
6. つまずき：誤りやすい推論とその原因
7. 基本演習：理解と技能の検証
8. 接続：前提・発展・応用へのリンク

長文を増やすことを目的にしない。式の構造・図・段階的な導出・操作可能な可視化を優先する。証明と直観、公式の成立と公式の利用を混同しない。

## 注意事項

- 「必須事項」「思考力・判断力・表現力等」「用語・記号」「理解を支える補助概念」「発展」を区別する。
- 二項定理は学習指導要領解説で用語・記号に挙げられている。必須の技能項目と同じ重さで扱わない。
- 剰余の定理は因数定理の導出を見通すための補助定理として位置づける。
- 共役複素数は四則演算を理解する補助概念として扱い、単元の中心目標と混同しない。
- 学習指導要領の範囲を超える説明は、発展として明示する。
