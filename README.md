# Math-OS

高校数学の基礎を、暗記する解法の集合ではなく、意味・定義・原理・関係から理解するための学習基盤。

## 目的

Math-OS が担うのは、学習の第1段階である「基礎理解・基礎技能」。

1. **基礎理解・基礎技能（Math-OS）** — 概念・定義・性質・基本操作を理解する。
2. **網羅・典型問題** — 基本事項を組み合わせ、典型構造に対応する。
3. **入試演習** — 未知の問題を分析し、方針を立てて統合的に解く。
4. **志望校別演習** — 大学ごとの要求に適応する。

難問を大量に集めるのではなく、基礎を深く理解し、自力で使える状態をつくる。

## 制作方針

- 制作は **数学II** から開始する。
- 数学I「数と式」は既習事項の確認・参照を中心に簡潔に扱う。
- それ以外の未習領域は、必要な前提から丁寧に構築する。
- 科目別カリキュラム、概念ネットワーク、数学的テーマという複数の見方を用意する。
- 数学的な前提関係と、学校で教える順序を区別する。
- 定義・導出・成立条件・複数表現・基本演習を、概念に応じて設計する。
- 可視化は装飾ではなく、数学的関係を観察・操作するために使う。
