# 高校数学カリキュラムマップ（設計草案）

> 状態: draft。これは制作・整理のための作業用マップであり、学習指導要領や特定教科書の目次をそのまま転記した確定版ではない。正式な範囲・用語・選択内容は、文部科学省の学習指導要領・解説および複数の現行教科書と照合して確定する。

## 1. 目的と読み方

このマップは高校数学全体を見渡すための索引である。科目の章立てを概念体系そのものとはみなさず、科目タグと概念ネットワークを分けて管理する。

制作開始単元は **数学II**。数学I「数と式」は既習事項の参照・確認を中心に簡潔に扱う。それ以外の単元は、必要な前提を確認しながら初学者にも通じる説明を作る。

### 二次関数
- 関数とグラフ
- 二次関数のグラフと平方完成

## 8. 数学IIの制作順（暫定）

1. いろいろな式
2. 図形と方程式
3. 指数関数・対数関数
4. 三角関数
5. 微分・積分の考え

この順序は仮の制作順であり、最終的な学習順は前提関係・理解の自然さ・カリキュラム上の制約を検討して決める。必要なら単元内の順序も組み替える。
